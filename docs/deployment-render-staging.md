# Deployment staging AMS di Render

> **Panduan legacy.** Blueprint Render sebelumnya memerlukan paket berbayar dan sudah dihapus dari repository. Jangan mengikuti langkah lama yang merujuk `render.yaml`.

Untuk deployment Firebase staging, gunakan [panduan VPS Windows](./panduan-deploy-vps-windows.md) atau [panduan Oracle Cloud Always Free](./deployment-oracle-free-preview.md), sesuai server yang dipakai.
